# Complete-Vector-Collection

**Currently in WIP with additional changes and improvements to be added.**

This project consists of a complete vector collection system, which includes a template collection system with all the readily available functions and implementations to use in .cpp programs. The collection includes STL libraries, standard ADT behaviors, such as list, stack, and queue behaviors, and basic exception handling. To test the collection, first create a .cpp executable, then test every function in the header file. It is recommended print the vector after each function call, and it is optional to document the compute time of the sorting and searching functions to demonstrate time complexity of different algorithms.

**Note (1):** quickSort() uses last element partition, otherwise known as the Lomuto partition scheme. This produces $O(n^2)$ performance and potentially $O(n)$ recursion depth in worst cases. This design choice was made for simplicity of the algorithm, while other partition schemes are potentially more performant, but complex to implement. sort() only uses quickSort() when the collection size is within the interval $50 < n <= 150000$. By default, the QuickSort() algorithm is private implemented but not used officially in the sort() function. Benchmark this algorithm independently and determine to what collection size does it fit best.

**Note (2):** This collection has a flexible duplication policy. It consists of a compile-time parameter when constructing the collection that allows the user to choose whether to allow duplicates or reject them. For example, $Collection<int, DuplicationPolicy::Allow>$ constructs an integer collection and allows duplicates. It also has a runtime parameter for removal, replacement, and swapping functions that the user can choose to remove/replace/swap all duplicate values or the first occurrence of such. For example, $remove(5, OccurrenceMode::First)$ only removes the value 5 from the first occurrence of it in the collection.
